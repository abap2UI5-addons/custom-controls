abap2UI5 custom controls

This BSP is a module container, not an application - it has no UI of its own. It serves the custom controls under cc/ to the abap2UI5 frontend, which resolves them through the reserved resourceRoot z2ui5ccc declared in its manifest.json.

Start the demo app on the abap2UI5 endpoint instead: ?app_start=z2ui5_cl_cci_sample_00
