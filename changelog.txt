custom-controls changelog
=========================

Legend
------
* : fixed
! : changed
+ : added
- : removed


unreleased
----------
* SignaturePad: clearing the bound value from ABAP (signature = ``) blanks the pad - the canvas survives a re-render with its picture, so the strokes stayed visible and the next stroke sent the old ones along. A new value goes onto the running canvas without a re-render
! SignaturePad: value draws only a data:image/ URL - any other (an http(s) URL above all) is logged and never requested, the pad stays blank
* RichTextEditor: an edit made in code view reached neither the model nor the change event - the editor read only the WYSIWYG area, and the code area reports no blur. Leaving the code area now publishes and fires change as the editor does, and a roundtrip started from the code view sends what it shows
* GridStack: dragging or resizing a box no longer raises itemPress - the click that ends the gesture is not a press
* ImageMapster: an image that does not load is logged instead of leaving the map silently without areas; a re-render drops the load listener of the image it replaced
* DriverJs, ImageMapster, ExportSpreadsheet: an option whose library default is true could not be switched off - bound with omit_initial an abap_false is dropped. These fields are ty_flag (text) now, as in ChartJs: cs_flag-false switches the option off, cs_flag-true or abap_true on, empty keeps the default; an assignment of abap_true or abap_false compiles and behaves as before. DriverJs: animate, allow_close, allow_keyboard_control. ImageMapster: fill, fade, highlight, is_selectable, is_deselectable, render_highlight/render_select fill, stroke and fade, and an area's isselectable. ExportSpreadsheet: display_unit, auto_scale, display_timezone, utc
* DriverJs (stage_padding, stage_radius, popover_offset), ExportSpreadsheet (scale) and ChartJs (ticks-step_size, scale-suggested_min/suggested_max, the tension animation's from and to) could not send 0, ChartJs not a fraction either - omit_initial drops a 0. They are text now: empty keeps the default, `0` and `0.5` are sent as numbers; an assignment of an integer compiles as before
+ DriverJs, ImageMapster, ExportSpreadsheet, Gauge (options): the control turns the ABAP field names into camelCase itself, as ChartJs does, so the structure is bound with omit_initial alone - the obsolete camelCase mapper is no longer needed (it still works); samples 02, 06 and 09 drop it
+ z2ui5_cl_cci=>bool( ) turns an ABAP flag into the `true` / `false` a boolean render( ) parameter takes - abap_false passed as it is becomes an empty string, the attribute is dropped and the control keeps its default (editable = abap_false left a field editable)
+ Barcode: render( ) takes barwidth, the width of a linear symbol in millimetres - the control had the property, the builder did not reach it
* Clock: the OverflowToolbarLayoutData of priority declares its namespace sap.m itself - in a view whose default namespace is not sap.m it named a control that does not exist and the view failed to load
+ FontAwesome: cssurl = z2ui5_cl_cci_font_awesome=>c_no_css loads no stylesheet - the documented "pass a space" did not work with a ' ' literal, which turns into an empty string
* DriverJs, Validator: a view rebuilt by view_display (e.g. after a navigation back) no longer starts the last tour or runs the last check again - the trigger value a new control instance is built with counts only when the previous instance at the same binding did not already have it
! DriverJs: popover title, description, progress and button texts are plain text now (escaped) - driver.js wrote them with innerHTML; allowhtml = `true` takes HTML again, sanitized with DOMPurify (purifyurl)
* ChartJs: a plugin (datalabels, autocolors, deferred) is handed to the one chart that names it instead of being registered page-wide, where it changed every other chart on the page; annotation and the chart types venn and wordcloud still need Chart.js' registry
* Validator: required fails an unticked CheckBox, a Switch that is off (Switch was not read at all) and a MultiComboBox or MultiInput with nothing selected - their selected keys / tokens are read instead of the typed text
+ CDN build: every library URL carries a Subresource Integrity hash (sha384, generated by npm run vendor and checked in CI); the Font Awesome IconPool directory is pinned to a commit of its repository
* CodeEditor: no second editor (duplicate id) when the control re-rendered while sap.ui.codeeditor was still loading
* ExportSpreadsheet: the SAPUI5/OpenUI5 check runs once per page, asynchronously, instead of a synchronous version info request on every rendering
* NetworkStatus: the icon size is set outside the renderer; a stopped ping monitor is dropped after one interval and a stale result is not shown as current
* AnimateCss: several instances share the page-wide variables - the last one rendered wins, and exit( ) restores the previous instance's or the page's own values instead of removing them
* UI5 1.71 to 1.92: Util.isDestroyed probes the destroyed flag (isDestroyed( ) is 1.93) - async callbacks no longer touch a destroyed control; SignaturePad, NetworkStatus and ScanInput use the shared Util helpers
! z2ui5_cl_cci_json_filter is deprecated - nothing here uses it, _bind( omit_initial = abap_true ) replaces it; it will be removed in a later release
* Validator: a minimum or maximum of 0 was never checked - omit_initial drops it, and without omit_initial every untouched limit was 0. minimum and maximum are text now: empty means no limit, `0` is a limit like any other, and a fraction such as `2.5` works too; an assignment of an integer compiles as before
* ChartJs: an option whose Chart.js default is true (responsive, legend-display, tooltip-enabled, ticks-display, grid-draw_on_chart_area, ... - 28 fields) could not be switched off: bound with omit_initial an abap_false is dropped and Chart.js falls back to true. These fields are ty_flag (text) now - cs_flag-false switches the option off, cs_flag-true or abap_true on, empty keeps the default; an assignment of abap_true or abap_false compiles and behaves as before
+ ChartJs: the control turns the ABAP field names into camelCase itself, so config is bound with omit_initial alone - the obsolete camelCase mapper is no longer needed (it still works)
* ChartJs: line-tension and datalabels-opacity were integers and could not hold a fraction (ty_fraction now); legend-full_size was an integer (ty_flag now)
! BREAKING ChartJs: the dash patterns (border-dash, grid-border_dash, grid-tick_border_dash, angle_lines-border_dash, line-border_dash, arc-border_dash) are ty_dash tables of segment lengths - Chart.js takes an array there, so a number or text never drew a dash. An app that assigned one gets a syntax error and writes VALUE #( ( 5 ) ( 5 ) ) instead
+ FloorPlan: an item with disabled = abap_true takes no click - no itempress, no selection, no pointer cursor
+ ScanInput: beeponsuccess = `true` plays a short, high tone when valuestate turns to Success - the scan was taken
+ FloorPlan: zoomable = `false` makes the plan a fixed picture of the whole - no wheel, drag, pinch, keys or buttons, the page scrolls as usual, a click still selects
+ FloorPlan (z2ui5_cl_cci_floor_plan, sample 18): a plan of boxes from an ABAP table, each with a position, a state and a fill level, that the user zooms and pans with the wheel, a drag or two fingers; the closer the view, the more text a box shows, a click raises "itemPress" with its key, and "fitkeys" flies the viewport to items from ABAP. Plain SVG, no library
+ Gauge (z2ui5_cl_cci_gauge, sample 16): a round gauge with a scale, coloured zones and a needle that follows the bound value, drawn by canvas-gauges 2.1.7
+ GridStack (z2ui5_cl_cci_gridstack, sample 17): boxes on a grid from an ABAP table, shown or dragged and resized by the user with gridstack.js 14.1.1; the new positions are written back into the table before the event "change" is raised
+ ScanInput: a focus sequence over several scan fields - bind keepfocus of each field to a flag; the field whose flag turns on while it is on screen takes the focus, also from another text field (a popup, a hidden or a disabled field still make it wait)
+ ScanInput: uppercase = `true` turns what is typed, scanned or pasted into capital letters in the field, so value, submit and change carry them
! BREAKING: four classes renamed so that every class name has at most 25 characters and the namespace rename takes a name of the full 10 characters (it was capped at 6): z2ui5_cl_cci_rich_text_editor -> z2ui5_cl_cci_rich_text, z2ui5_cl_cci_barcode_scanner -> z2ui5_cl_cci_barcode_scan, z2ui5_cl_cci_network_status -> z2ui5_cl_cci_net_status, z2ui5_cl_cci_signature_pad -> z2ui5_cl_cci_signature. Methods, parameters, types and constants are unchanged, and so are the controls in the BSP (z2ui5_cci.cc.RichTextEditor, ...). An app changes the class name it calls; after the abapGit pull the four old classes are still on the system - abapGit does not delete them - and must be deleted by hand (SE24 or ADT) once no app uses them
